# Revenue Cycle — RC12 Accounts Receivable

Production Accounts Receivable foundation for patient-level receivables.

Design:
- canonical `patient_core.Patient`
- explicit tenant and organization context
- platform RBAC
- API -> workflow -> policy -> service -> selector -> model -> event
- `select_for_update()` on balance mutations
- immutable transaction records with reversal instead of destructive edits
- after-commit domain events
- organization-scoped uniqueness
- no migrations generated by this installer
